# Doodle Sky 🐣☁️

Бесконечный вертикальный прыгательный платформер в духе Doodle Jump.
Работает прямо в браузере, без интернета и установки — просто открой `index.html`.

## Как запустить
1. Распакуй архив в любую папку.
2. Открой файл `index.html` двойным щелчком (или через File → Open в браузере).
3. Chrome / Edge / Firefox / Safari — подойдёт любой современный браузер.

Если хочешь открыть игру с телефона в локальной сети, можно запустить простой
локальный сервер из папки с игрой, например `python3 -m http.server`, и зайти
по адресу `http://<IP-компьютера>:8000`.

## Управление
- **Касание экрана (без видимых кнопок):** экран поделён на 3 невидимые зоны.
  - Левая треть — держать, чтобы двигаться влево.
  - Правая треть — держать, чтобы двигаться вправо.
  - Средняя треть — держать, чтобы стрелять очередью вверх.
  Зоны читают несколько пальцев одновременно (можно держать движение одной
  рукой и стрелять другой), реализовано на Pointer Events с учётом
  `pointerId`, так что работает и с мышью, и с тачем.
- **Клавиатура:** ← → или A / D — движение, **Пробел / ↑ / W** — стрельба,
  **Esc / P** — пауза.
- Персонаж прыгает автоматически при приземлении на платформу, экран
  «заворачивается» по горизонтали — уйдя за левый край, ты появишься справа.

## Игровые механики
- **Платформы:**
  - 🟢 обычные — можно прыгать бесконечно;
  - 🔵 движущиеся — едут влево-вправо;
  - 🟤 разрушающиеся — выдерживают один прыжок и рассыпаются.
- **Бонусы на платформах:**
  - 🌀 пружина — очень высокий прыжок;
  - 🚀 ранец — несколько секунд автоматического полёта вверх и неуязвимость;
  - 🌬 пропеллер — медленное падение и повышенная манёвренность в воздухе;
  - 🛡 щит — гасит одно столкновение с врагом.
- **Враги:**
  - фиолетовый шипастый монстр сидит на платформе;
  - крылатый летающий враг летает туда-сюда по экрану.
  Столкновение с врагом без щита завершает игру — но теперь врагов можно
  **отстреливать** заранее.
- **Стрельба (как в оригинальном Doodle Jump):** Дудл всегда может стрелять
  вверх — снаряд летит по прямой от игрока и уничтожает любого врага на
  своём пути, принося +30 очков. Скорострельность ограничена небольшой
  задержкой между выстрелами, так что это инструмент, требующий прицеливания
  по горизонтали, а не спам-кнопка.
- **Звёзды** — плавают в воздухе, дают +50 очков при касании.
- **Смена фона** — по мере подъёма небо меняется: день → закат → сумерки → ночь
  со звёздами, затем цикл повторяется в новой цветовой гамме.
- **Очки** = высота подъёма + бонусы от звёзд. Рекорд сохраняется в браузере
  (localStorage) и показывается в меню.
- Сложность растёт постепенно: чаще появляются движущиеся/разрушающиеся
  платформы и враги, дальше приходится прыгать между платформами.

## Свои скины
На главном экране — кнопка **«Свой скин»**:
- можно загрузить картинку для **дудла** (игрока) и отдельно — для **врагов**;
- изображение сохраняется в этом браузере (localStorage), поэтому применится
  и в следующий раз, пока не нажмёшь «Сбросить»;
- лучше всего смотрятся квадратные PNG с прозрачным фоном — картинка
  вписывается в круг персонажа, сохраняя пропорции;
- ограничение — 3 МБ на файл (это просто чтобы не забить localStorage).

Скины хранятся только локально на твоём устройстве, никуда не отправляются.

## Интеграция с VK Bridge (игры ВКонтакте)
Игра подключает `https://unpkg.com/@vkontakte/vk-bridge/dist/browser.min.js`
в `<head>` и полностью рабочая как внутри ВК, так и вне его — если скрипт
не загрузился (например, ты просто открыл `index.html` локально или
захостил игру не в ВК), объект `vkBridge` отсутствует и все вызовы SDK
превращаются в no-op. Игра при этом ведёт себя как обычно, просто без
рекламы и облачного сохранения.

Что уже сделано в `game.js`:
- **`vkBridge.send('VKWebAppInit')`** запускается при загрузке — это
  обязательный вызов, без него ВК не отпустит приложение с экрана загрузки
  и не пропустит модерацию. Сразу после успешной инициализации игра читает
  язык через **`VKWebAppGetLaunchParams`** (`vk_language`). Сейчас сборка
  локализована на русский, поэтому для неподдерживаемого языка используется
  русский fallback.
- **Межстраничная реклама (`VKWebAppShowNativeAds`, `ad_format: 'interstitial'`)**
  показывается не после каждой смерти, а раз в 3 забега (счётчик
  `goCountSinceAd`), чтобы не раздражать игрока — частоту легко поменять в
  `maybeShowInterstitial()`. Перед показом всегда проверяется доступность
  через `VKWebAppCheckNativeAds`.
- **Реклама за вознаграждение (`VKWebAppShowNativeAds`, `ad_format: 'reward'`)**
  — на экране Game Over при доступности рекламы появляется кнопка
  «📺 Продолжить (реклама)», разово за раунд: досмотрел ролик — Дудл
  возрождается на безопасной платформе рядом с текущей высотой, ближайшие
  враги убираются, счёт не сбрасывается. Та же механика — кнопка «Щит за
  рекламу» в меню паузы.
- **Облачное сохранение рекорда** — через `VKWebAppStorageGet`/
  `VKWebAppStorageSet` (ключ `highscore`), без запроса дополнительных
  разрешений у игрока. Если облачное значение больше локального —
  подтягивается оно, если локальное больше — заливается в облако. Скины
  **не** синхронизируются в облако (это большие base64-картинки, и лимиты
  VK-хранилища для них не рассчитаны) — они остаются только на устройстве,
  как и раньше.
- **`document.documentElement.requestFullscreen()`** — при нажатии «Играть»
  игра пытается развернуться на весь экран через стандартный браузерный
  Fullscreen API (полезно на мобильных, если разрешено iframe-песочницей
  ВК; если нет — просто ничего не происходит).
- У VK нет прямого аналога Yandex-совместимого «GameplayAPI» (сигнала «идёт
  активный геймплей») — соответствующие функции оставлены как пустые
  заглушки, чтобы не трогать остальной код.
- **`vkBridge.subscribe(...)` на событие `VKWebAppViewHide`** — это пункт
  модерации ВК: звук обязан останавливаться, когда пользователь сворачивает
  мини-приложение внутри клиента VK (обычный `visibilitychange` браузера
  для этого не подходит, т.к. приложение живёт в управляемом VK iframe).
  При этом событии игра гасит `AudioContext` и, если раунд был активен,
  сама ставит игру на паузу — это уже добавлено в `game.js`.

### Как опубликовать в играх ВКонтакте
1. Зайди в [личный кабинет разработчика ВКонтакте](https://dev.vk.com/) →
   «Мои приложения» → «Создать приложение» → тип **«Игра»**.
2. Собери загрузочный **zip-архив, в корне которого сразу лежит
   `index.html`** (без вложенной папки) — именно так и упакован архив
   из этого комплекта, его можно загружать как есть.
3. Залей архив в разделе настроек приложения, отвечающем за загрузку
   HTML5-сборки.
4. Укажи ориентацию **«книжная» (portrait)** — макет рассчитан на
   вертикальный экран (400×650 логических пикселей). Игровая область — это
   **фиксированная виртуальная композиция** 400×650, которая целиком
   масштабируется под экран через `fitStage()` в `game.js`
   (`transform: scale(...)` на `#app`, letterbox scaling / scale-to-fit) —
   та же техника, что и в пасьянсе. Благодаря этому вёрстка не «плывёт» и
   не обрезается ни при масштабе браузера 100/125/150%, ни на разных
   экранах: `html`/`body` намертво зафиксированы
   (`position:fixed; overflow:hidden`), скроллбар в игре в принципе
   невозможен, а `resizeCanvas()` дальше просто подгоняет физическое
   разрешение канваса (с учётом `devicePixelRatio`) под уже
   отмасштабированный визуальный размер `#app`, чтобы графика не мылилась.
5. Пройди модерацию — она проверит, что `VKWebAppInit` вызывается сразу при
   загрузке (иначе приложение зависнет на экране загрузки), что игра
   технически рабочая и не использует запрещённые API. Актуальные
   требования и шаги лучше сверить в документации на [dev.vk.com](https://dev.vk.com/),
   так как правила и интерфейс кабинета периодически меняются.
6. Заполни карточку приложения (иконка, скриншоты, описание, возрастной
   рейтинг) и отправь на модерацию.

### Что можно донастроить перед публикацией
- Подобрать частоту интерстишлов под свои метрики удержания
  (`goCountSinceAd` в `game.js`).
- При желании — баннерная реклама (`VKWebAppShowBannerAd` /
  `VKWebAppCheckBannerAd`), в этой сборке не используется, чтобы не
  перекрывать игровое поле на маленьких экранах.
- Авторизация игрока (`VKWebAppGetUserInfo`) и социальные механики
  (шеринг результата на стену, приглашение друзей) — тоже не включены в
  эту сборку, но легко добавляются через VK Bridge при необходимости.

## Структура проекта
```
doodle-sky/
├── index.html   — разметка экранов (меню, игра, настройка скинов, пауза, game over)
├── style.css    — оформление в «doodle»-стиле (шрифты Baloo 2 / Nunito)
├── game.js      — весь движок игры: физика, генерация уровня, рендер, скины
└── README.md    — этот файл
```
Игра написана на чистом JavaScript + Canvas 2D, без сторонних библиотек и
без сборки — можно смело открывать и редактировать `game.js` напрямую.

## Что можно докрутить дальше
