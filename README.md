Управление

Касание экрана (без видимых кнопок): экран поделён на 3 невидимые зоны.

Левая треть — держать, чтобы двигаться влево.

Правая треть — держать, чтобы двигаться вправо.

Средняя треть — держать, чтобы стрелять очередью вверх. Зоны читают несколько пальцев одновременно (можно держать движение одной рукой и стрелять другой), реализовано на Pointer Events с учётом pointerId, так что работает и с мышью, и с тачем.

Клавиатура: ← → или A / D — движение, Пробел / ↑ / W — стрельба, Esc / P — пауза.

Персонаж прыгает автоматически при приземлении на платформу, экран «заворачивается» по горизонтали — уйдя за левый край, ты появишься справа.
